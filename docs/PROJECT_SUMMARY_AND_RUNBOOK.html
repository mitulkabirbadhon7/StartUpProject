1. Executive Summary & Design Directives

The European Gastronomy Web Demos platform delivers two bespoke, Michelin-caliber digital showcases designed to demonstrate how independent European restaurateurs can eliminate third-party aggregator commissions (15-30% on platforms like OpenTable or TheFork), enforce full European regulatory compliance (GDPR and EU-14 allergen tracking), and substantially elevate beverage and tasting menu ticket averages through interactive sommelier pairings.

Strict Anti-AI Slop Mandate: In full compliance with project quality directives, this repository contains zero AI/Gemini logos, zero robotic glyphs, and zero generic purple-to-cyan SaaS gradients. Every interface embodies European tactile luxury: Warm Espresso (#2A1E17), Stone Ivory (#F7F4EE), Deep Bordeaux (#5E1924), and Butter Yellow (#F3E5AB).

2. Monorepo Architecture

The solution is organized as an npm workspaces monorepo with clean separation of concerns:

  • /frontend: Next.js 15 App Router, React 19, Tailwind CSS, Framer Motion, and Lucide React. Pre-renders static high-performance landing pages for both dining venues.
  • /backend: Node.js & Express.js REST API with Drizzle ORM connecting to Neon Serverless PostgreSQL. Hardened with Helmet, CORS, and rate limiting.
  • /shared: Universal single source of truth exporting Zod validation schemas and TypeScript DTOs shared synchronously across client and server.
  • /docs: Engineering specifications, database schemas, phased implementation blueprints, and this operational runbook.

3. Flagship Interactive Features

3.1 Interactive SVG Floorplan & Seat Selector

Guests can visually explore distinct dining zones (Heated Garden Terrace, Grand Dining Hall, Sommelier Wine Vault, Chef's Counter) and reserve specific tables with real-time capacity and acoustic ambient notes. Table selections seamlessly pre-populate the reservation drawer.

3.2 EU-14 Allergen & Dietary Matrix Filter

Full compliance with EU Directive 1169/2011. Allows immediate filtering by dietary preferences (Vegan, Vegetarian, Gluten-Free, Dairy-Free, Halal) and individual exclusion of European mandatory allergens (fish, nuts, eggs, gluten, milk).

3.3 Sommelier Pairing Engine with 5-Axis Flavor Radar

Every dish is dynamically paired with certified European wines or aperitifs. An interactive SVG radar chart plots Acidity, Tannins, Body, Oak, and Intensity on a 5-point scale, offering sommelier tasting notes, vintage, and regional terroir context.

3.4 European Reservation Drawer with iCalendar (.ics) Sync

A 3-step tactile reservation workflow requiring explicit GDPR consent. Upon confirmation, generates a unique European booking reference code and an RFC 5545 .ics calendar file for one-click Apple Calendar / Google Calendar integration.

5. Quickstart & Deployment Runbook

5.1 Local Development

# 1. Clone repository
git clone https://github.com/mitulkabirbadhon7/StartUpProject.git
cd StartUpProject

# 2. Install dependencies
npm install

# 3. Build shared packages
npm run build --workspace=shared

# 4. Run automated test suite
npm test

# 5. Start development servers
npm run dev:backend   # Express REST API (port 5000)
npm run dev:frontend  # Next.js 15 Web Application (port 3000)

5.2 Production Deployment

The monorepo can be deployed with the frontend on Vercel and the backend on Railway, Render, or Fly.io with a managed Neon Serverless PostgreSQL instance.

  • Frontend Root: frontend | Build Command: npm run build | Output: .next
  • Backend Root: backend | Build Command: npm run build | Start: npm start
  • Database: Neon Serverless PostgreSQL with SSL (DATABASE_URL=...?sslmode=require)
