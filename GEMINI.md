# Project Workspace Configuration & Context

## Project: European Dining Web Demos
**Lead Developer:** Mitul Kabir Badhon  
**GitHub Profile:** https://github.com/mitulkabirbadhon7  
**Core Technologies:** Next.js 15, TypeScript, Tailwind CSS, shadcn/ui, Zod, Node.js, Express.js, Neon Serverless Postgres, Drizzle ORM.

### Key Rules & Requirements
1. **Bespoke Design, Anti-AI Slop:** Ultra-premium, editorial aesthetics tailored for European gastronomy.
2. **Zero AI / Gemini Logos:** No AI branding, logos, or synthetic placeholders anywhere in the repository.
3. **Decoupled Architecture:** Clean separation of `/frontend` and `/backend` with universal `/shared` schemas.
4. **Interactive Flagship Features:**
   - Live Table & Seat Selector (interactive SVG floorplan)
   - Smart Dietary & Allergen Matrix Filter
   - Sommelier Wine & Aperitivo Pairing Engine with Flavor Radar
5. **European Compliance:** GDPR consent banner, Impressum, multi-currency (€, £, CHF), multi-language support.
